# Customer Churn Prediction

Проект бинарной классификации для выявления клиентов телеком-компании с высоким риском ухода.

## Задача

По данным о подключённых услугах, типе договора, длительности обслуживания и платежах необходимо предсказать значение `Churn`:

- `0` - клиент останется;
- `1` - клиент уйдёт.

Такой прогноз позволяет заранее выделить группу риска и направить клиентам удерживающее предложение.

## Данные

Используется открытый датасет [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn), содержащий 7 043 наблюдения и 21 признак.

Доля ушедших клиентов составляет 26,5%, поэтому для оценки модели используются не только accuracy, но и recall, F1-score, ROC-AUC и PR-AUC.

## Что сделано

- проведён первичный и исследовательский анализ данных;
- обработан числовой признак `TotalCharges`;
- категориальные признаки преобразованы с помощью one-hot encoding;
- числовые признаки масштабированы;
- создан единый preprocessing и modeling pipeline;
- сравнены baseline, логистическая регрессия и случайный лес;
- выполнен подбор типа и силы регуляризации;
- проанализированы ошибки и коэффициенты итоговой модели.

## Результаты

Лучшей моделью стала логистическая регрессия с балансировкой классов и L2-регуляризацией при `C = 0.1`.

| Метрика | Значение |
|---|---:|
| Accuracy | 0.741 |
| Precision | 0.508 |
| Recall | 0.786 |
| F1-score | 0.617 |
| ROC-AUC | 0.841 |
| PR-AUC | 0.633 |

Модель обнаруживает 78,6% уходящих клиентов. Высокая полнота достигается ценой дополнительных ложных предупреждений, поэтому модель подходит для предварительного отбора клиентов перед недорогой удерживающей коммуникацией.

Наиболее высокий прогнозируемый риск связан с помесячным договором и оптоволоконным интернетом. Большая длительность обслуживания и двухлетний договор связаны с более низким риском ухода.
